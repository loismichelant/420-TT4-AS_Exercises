# Devoir 1 - Gestion d'un panier

## Instructions :

"Si vous le souhaitez, ajoutez ou retirez l'article de votre panier ; sinon, supprimez-le de la liste des produits."

---

## Description du travail réalisé

Pour ce devoir, j’ai ajouté un compteur permettant de suivre la quantité de chaque produit ajouté au panier.
Un bouton a également été implémenté afin de retirer un produit du panier, une unité à la fois.
Lorsque la quantité d’un produit atteint zéro, le bouton de suppression est automatiquement désactivé afin d’empêcher un retrait supplémentaire.
